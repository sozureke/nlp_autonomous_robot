# GitHub assets

Static files for the repository front page (README, wiki, etc.).

| File | Role |
|------|------|
| **`demo.gif`** | Main loop shown at the top of the root README — put your exported GIF here (same path/name). |
| `demo-poster.png` | Optional thumbnail if you later switch to a video link instead of GIF |
| `demo.mp4` | Optional full-quality clip (README usually won’t embed it; host externally or attach as download) |

**Note:** GitHub’s README **does** render **`demo.gif`** inline when referenced as `![…](assets/demo.gif)`. Large GIFs slow down the repo; aim for a short loop and moderate resolution.
